# JobZap

Browser extension that cuts the noise from your LinkedIn job search. Supports both classic and new AI-powered LinkedIn search.

> 🚧 Work in progress, first version coming soon.

## Filters

- Hide **viewed** jobs
- Hide **applied** jobs
- Hide **dismissed** jobs
